## 📋 Описание

Arizona RP Launcher — это полнофункциональное решение для запуска и настройки игры на серверах Arizona RP. Лаунчер предоставляет удобный интерфейс для управления патчами, скриптами и параметрами запуска игры.

### ✨ Основные возможности

**🚀 Запуск игры**
- Интеграция с лаунчером Air (v6 и v7)
- Автоматическое определение пути к игре
- Сохранение последнего никнейма и сервера
- Поддержка всех параметров запуска (память, графика, оконный режим и др.)
- Автоматическое добавление в исключения Windows Defender

**⚙️ Управление патчами**
- Редактор настроек ArizonaPatches с удобным интерфейсом
- Импорт/экспорт конфигураций патчей
- Система бэкапов (до 15 автоматических резервных копий)
- Восстановление из бэкапов одним кликом
- Магазин готовых пресетов патчей

**🎨 Персонализация**
- Кастомные обои для интерфейса
- Встроенная коллекция обоев
- Загрузка собственных изображений
- Современный дизайн с эффектами прозрачности и анимациями

**📜 Moonloader**
- Менеджер скриптов с включением/отключением
- Встроенный магазин скриптов
- Удаление ненужных скриптов
- Быстрый доступ к папке moonloader

**📰 Новости и информация**
- Лента новостей лаунчера
- Отметка непрочитанных новостей
- Информация о серверах в реальном времени
- Онлайн и очередь на каждом сервере

**🔧 Дополнительно**
- Система профилей с разными настройками
- Менеджер дополнительных файлов (CLEO, ASI, плагины)
- Подробная отладочная информация
- Сворачивание в системный трей
- Автоматическая установка лаунчера Air

## 📦 Установка

### 🎯 Рекомендуемый способ: Готовый .exe (для Windows)

1. Перейдите в раздел [Releases](https://github.com/worteng/ArizonaLauncher/releases)
2. Скачайте последнюю версию установщика `ArizonaLauncher-v1.0.0.exe`
3. Запустите файл (может потребоваться запуск от имени администратора)
4. При первом запуске:
   - Лаунчер автоматически попытается найти игру
   - Если игра не найдена, укажите путь к папке с `gta_sa.exe` вручную
   - При необходимости будет предложена установка лаунчера Air

### 🛠️ Для разработчиков: Запуск из исходного кода

```bash
# Клонируйте репозиторий
git clone https://github.com/worteng/ArizonaLauncher.git
cd ArizonaLauncher

# Создайте виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate     # для Windows
source venv/bin/activate  # для Linux/macOS

# Установите зависимости
pip install -r requirements.txt

# Запустите лаунчер
python main.py
```

**Примечание:** Для корректной работы некоторых функций (добавление в исключения Defender) может потребоваться запуск от имени администратора.

## 🎮 Использование

### Первый запуск

1. **Автоопределение игры**
   - Лаунчер автоматически ищет игру в стандартных путях
   - Если игра найдена, можно сразу начать играть

2. **Ручная настройка**
   - Нажмите "Выбрать папку с игрой"
   - Укажите папку, где находится `gta_sa.exe`
   - Лаунчер проверит наличие необходимых компонентов

3. **Установка лаунчера Air** (требуется)
   - Выберите версию: v6 (стабильная) или v7 (новая)
   - Дождитесь завершения установки
   - Готово к запуску!

### Основные функции

**Запуск игры:**
1. Введите никнейм (сохраняется автоматически)
2. Выберите сервер из списка
3. Нажмите "Начать игру"

**Настройка патчей:**
1. Откройте "Настройки" → вкладка "Патчи"
2. Включите/выключите нужные патчи
3. Сохраните изменения
4. Можно экспортировать конфигурацию или загрузить готовый пресет

**Управление скриптами:**
1. Откройте "Настройки" → вкладка "Moonloader"
2. Включайте/выключайте скрипты переключателями
3. Устанавливайте новые скрипты из каталога
4. Удаляйте ненужные скрипты

**Профили:**
1. Создайте профиль с уникальными настройками
2. Переключайтесь между профилями одним кликом
3. Каждый профиль сохраняет свои параметры запуска

## 🛠️ Технологии и архитектура

### Backend (Python)
- **pywebview** — создание нативного окна с WebView2
- **requests** — загрузка данных с серверов и GitHub
- **psutil** — управление процессами (завершение старых экземпляров)
- **PyQt5** — диалоги выбора файлов и папок
- **pystray** + **Pillow** — сворачивание в системный трей (опционально)

### Frontend (HTML/CSS/JavaScript)
- Чистый JavaScript (без фреймворков)
- CSS3 с современными эффектами (backdrop-filter, animations)
- Адаптивный дизайн
- Шрифт: Montserrat Alternates + Segoe UI

## ❓ FAQ (Часто задаваемые вопросы)

<details>
<summary><b>Лаунчер не запускается / вылетает при запуске / требует права админа</b></summary>

Убедитесь что установлены:
- Microsoft Edge WebView2 Runtime
- Visual C++ Redistributable 2015-2022

При первом запуске лаунчер предложит установить недостающие компоненты.
Запустите от администратора.
</details>

<details>
<summary><b>Не находит игру автоматически</b></summary>

Укажите путь вручную:
1. Нажмите "Выбрать папку с игрой"
2. Выберите папку где находится `gta_sa.exe`
3. Обычно это: `C:\Program Files\Arizona Games Launcher\bin\arizona\`
</details>

<details>
<summary><b>Антивирус блокирует лаунчер</b></summary>

Это ложное срабатывание. Лаунчер:
- Имеет открытый исходный код
- Не содержит вредоносного кода
- Автоматически добавляет лаунчер Эира в исключения Windows Defender

Если используете другой антивирус — добавьте лаунчер в исключения вручную.
</details>

<details>
<summary><b>Как обновить лаунчер?</b></summary>

1. Скачайте новую версию из [Releases](https://github.com/worteng/ArizonaLauncher/releases)
2. Удалите старую версию и установите новую
3. Все настройки сохранятся (они хранятся в `Documents\ArizonaLauncher\`)
</details>

<details>
<summary><b>Где хранятся настройки?</b></summary>

Все настройки и бэкапы хранятся в:
```
C:\Users\[ИМЯ_ПОЛЬЗОВАТЕЛЯ]\Documents\ArizonaLauncher\
├── config.json          # Основные настройки
└── backups/             # Бэкапы патчей
```
</details>
